# NOTE TAKING ASSISTANT AI 


## Overview


## REQUIREMENTS

**Note Taking Assistant AI** is a project designed to improve the traditional note taking experience by integrating AI-powered assistance. Rather than simply recording information, the system aims to help users understand, organize, and improve their notes in real time.

The project addresses common challenges in note-taking, such as incomplete explanations, inaccurate information, and difficulties creating diagrams or graphs during lectures and meetings.

By providing features such as real-time problem solving, fact-checking, diagram generation, summarization, and automatic corrections, the system aims to make note-taking more efficient, interactive, and useful for students and professionals.

## Features
### 1. Real Time 
Provides AI-powered suggestions and feedback while users take notes, helping them improve clarity and understanding without manually requesting assistance.

### 2. Problem solving
Assists users in solving mathematical problems and other questions directly within their notes, providing explanations and step-by-step solutions.

### 3. Graph and Chart Generation
Helps users create graphs, charts, and diagrams to visualize information, reducing the time and effort required to draw them manually.

### 4. Fact-Checking
Identifies potential inaccuracies, incorrect calculations, and misleading information in notes, helping users maintain accurate and reliable content.

### 5. Summarization and Automatic Corrections

Generates concise summaries of notes while suggesting corrections and improvements to make the content clearer, more organized, and easier to review.



 ## Requirements

 Before running the project, make sure you have the following:
- **Python 3.9+**
- **Anthropic API Key**
- **pip** – Python package manager  
    
**Requirements:** Python 3.9+ and an Anthropic API key.
 

## Installation and How to Run
Install the required dependencies using the following command:
```bash
pip install -r requirements.txt
```

### Configuration
Set up your Anthropic API key before running the application.

 ### Windows (PowerShell): 
```powershell
# Windows PowerShell
$env:ANTHROPIC_API_KEY="your-api-key-here"
```
### macOS / Linux:
```bash
# macOS / Linux
export ANTHROPIC_API_KEY="your-api-key-here"
```
 
### How to Run
Once the dependencies are installed and the API key is configured, start the server using:
 
```bash
python server.py
```
